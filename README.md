# PM Assistant

Личный AI-помощник директора по продукту: захват сырых мыслей, разбор их Claude
на задачи / заметки / темы для 1:1, и поиск-вопросы по всей базе.

Чистый **Vanilla JS** (ES-модули), без фреймворков и сборки. Данные — в `localStorage`.

## Вкладки

- **Захватить** — пишешь поток мыслей, Claude разбирает его на структурированные
  черновики (тип, приоритет, дедлайн, человек). Правишь и сохраняешь.
- **Задачи** — список всех элементов с фильтрами по типу и статусу, чекбоксы «готово».
- **Найти** — задаёшь вопрос на естественном языке («что обсудить с Леной?»),
  Claude отвечает по базе и подсвечивает релевантные элементы.

## Запуск

API запрещает запросы с `file://`, поэтому нужен локальный сервер:

```bash
python3 -m http.server 8000
# открой http://localhost:8000
```

Ключ Claude можно вставить в окне **Настройки (⚙)** или скопировать
`config.example.js` → `config.js` и вписать там.

> ⚠️ Ключ хранится в браузере и шлётся напрямую в `api.anthropic.com`
> (`anthropic-dangerous-direct-browser-access`). Это для личного локального
> использования. Для продакшена ключ нужно прятать за бэкенд-прокси.

## Структура

| Файл | Роль |
|------|------|
| `index.html` | каркас SPA, три вкладки, модалка настроек |
| `style.css` | стили, тёмная/светлая тема через CSS-переменные |
| `app.js` | контроллер: роутинг вкладок, рендер, события (единственный трогает DOM) |
| `agent.js` | вызовы Claude API: `parseCapture`, `ask` |
| `storage.js` | CRUD поверх `localStorage`, версия схемы |
| `config.js` | локальный ключ/модель (в `.gitignore`) |

## Модель данных

Один корневой объект `pm_assistant_v1` в `localStorage`: `settings`, `items[]`, `people[]`.
Задача, заметка и тема — единый тип `Item` с полем `type` (`task` / `note` / `discussion`).
